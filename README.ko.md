# PiP

[English](README.md) | **한국어**

다른 일을 하면서 로그와 빌드 진행 상황을 확인하세요. PiP는 선택한 앱 창을 항상 위에 표시하는 읽기 전용 화면입니다. ScreenCaptureKit으로 캡처하고 Metal로 표시합니다.
빌드 출력이나 대시보드를 살펴볼 때 유용하지만 화면 갱신은 원본 앱의 렌더링에 달려 있습니다.

웹사이트: <https://hanbong5938.github.io/pip/ko/>

상세 문서: [한국어 Wiki](https://github.com/hanbong5938/pip/wiki) — 설치, 사용법, 설정, 문제 해결, 빌드 및 구조

> [!WARNING]
> ad-hoc 서명된 실험적 프리뷰입니다. 다른 데스크톱(Space)에 PiP 창이 보인다고 해서 원본 화면이 계속 갱신되는 것은 아닙니다. [알려진 제한](#알려진-제한)을 참고하세요.

**공개된 preview.6:** 아래 고정 다운로드에는 이 문서의 숨김·재개, 원본 앱으로 이동, 설정 저장·복원 컨트롤이 포함됩니다. 현재 소스 빌드는 공개 바이너리와 다를 수 있으며, 실제 캡처와 복원은 잠금 해제된 Mac에서 수동 확인이 필요합니다.

## 기능

- macOS 시스템 선택기(`SCContentSharingPicker`)로 먼저 창 선택. 더 넓은 화면 기록 권한이 필요한 앱 안의 창 목록(PiP 창 또는 메뉴 막대)은 선택 사항
- 여러 PiP를 동시에 띄우고, 각 PiP마다 다른 창과 설정 사용
- PiP 창 위에서 직접 영역을 선택해 창의 일부만 표시
- PiP별 프레임 레이트: 1 / 5 / 15 / 30 / 60fps
- PiP별 불투명도
- 클릭 통과 모드: PiP 창이 클릭을 아래 창으로 넘김. 어느 앱에서든 ⌃⌥P로 전환
- PiP 화면을 90°씩 회전(표시 전용), 작게 / 보통 / 크게 크기 프리셋과 사용자 지정 크기
- 원본 창이 닫히면 PiP도 자동으로 닫는 옵션
- PiP 창에 마우스를 올리면 나타나는 컨트롤, 로그인 시 실행·새 PiP 기본값·단축키를 설정하는 설정 창
- PiP 창은 항상 위에 표시되며, 모든 데스크톱(Spaces)과 전체 화면 앱 위에서도 유지
- 메뉴 막대 전용 앱(Dock 아이콘 없음)
- 원본 비율 유지, 커서 미표시, PiP 창 크기에 맞춘 캡처 해상도
- 시스템 언어에 따라 한국어/영어 UI
- 캡처한 화면은 저장하거나 네트워크로 전송하지 않음

지원하지 않는 것: 오디오 캡처, PiP 창에서 원본 창으로의 클릭/키 입력 전달.

## 요구 사항

- Apple Silicon(arm64) Mac — 배포 바이너리는 arm64 전용
- macOS 15.2 이상
- 시스템 선택기는 앱 안의 창 목록에 필요한 더 넓은 권한 없이 사용자가 창을 골라 캡처할 수 있습니다. macOS가 캡처 동의를 요청할 수 있으며, 목록을 사용하려는 경우에만 더 넓은 화면 기록 권한을 허용하세요.

## 설치

### Homebrew

개인 tap([hanbong5938/homebrew-tap](https://github.com/hanbong5938/homebrew-tap))으로 제공합니다.

```sh
brew install --cask hanbong5938/tap/pip
```

삭제:

```sh
brew uninstall --cask pip
```

### 직접 다운로드

1. **동일한 preview.6 릴리스**의 [PiP-v1.0.0-preview.6-macos-arm64.zip](https://github.com/hanbong5938/pip/releases/download/v1.0.0-preview.6/PiP-v1.0.0-preview.6-macos-arm64.zip)과 [SHA256SUMS.txt](https://github.com/hanbong5938/pip/releases/download/v1.0.0-preview.6/SHA256SUMS.txt)를 받습니다. 두 파일을 한 폴더(예: 다운로드)에 둡니다.
2. 터미널에서 그 폴더로 이동해 해당 ZIP 항목을 확인합니다.

   ```sh
   cd ~/Downloads
   shasum -a 256 -c SHA256SUMS.txt
   ```

   `PiP-v1.0.0-preview.6-macos-arm64.zip: OK`가 표시될 때만 진행하세요. 파일이 없거나 명령이 실패하거나 ZIP이 `FAILED`로 표시되면 앱을 열지 말고 같은 릴리스에서 두 파일을 다시 받으세요. 체크섬은 받은 매니페스트와 파일이 일치하는지만 확인합니다. 배포자 신원을 인증하거나 ad-hoc 서명된 앱의 안전을 보장하지 않습니다.
3. 압축을 풀고 `Pip.app`을 `/Applications`로 옮긴 뒤 실행합니다.

### 서명 및 Gatekeeper

앱은 ad-hoc 서명만 되어 있으며 Developer ID 서명·Apple 공증을 받지 않았습니다. 설치 과정에 유료 개발자 등록이나 보안 우회는 필요하지 않습니다. macOS가 실행을 막으면 릴리스 출처를 별도로 신뢰할 수 있고 체크섬을 확인한 뒤 위험을 감수할 경우에만 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 사용하세요. Gatekeeper를 끄거나 격리 속성을 제거하지 마세요.

## 사용법

1. PiP를 실행하면 메뉴 막대 아이콘과 빈 PiP 창이 나타납니다.
2. **preview.6 또는 현재 소스 빌드**에서 **시스템 선택기로 창 선택…**으로 macOS 선택기에서 창을 고르세요. 목록용 권한은 필요하지 않으며, 한 번에 하나의 PiP만 선택기를 사용할 수 있습니다. 별도로 화면 기록 권한을 허용하면 PiP 창이나 메뉴 막대의 **창 선택 ▸** 목록도 선택적으로 사용할 수 있습니다. 목록을 불러오지 못한 경우는 빈 목록과 다르며, PiP 창을 열기만 해서는 권한을 자동 요청하지 않습니다. 목록 행의 **영역 선택**이나 메뉴에서 ⌥를 누른 영역 선택도 사용할 수 있습니다.
3. 선택한 경로에서 macOS가 요청하는 캡처 동의만 허용하세요. 선택 전에 원본 창이 사라지면 다시 고르세요.
4. PiP 창 배경을 드래그해 옮기고 가장자리를 끌어 크기를 조절합니다(최소 **영상 영역** 240×160포인트에 창 장식이 추가됨. 고정된 외부 창 크기 320×220이 아님). 캡처 중 원본 비율이 유지됩니다. PiP 창마다 크기와 위치는 다음 실행에도 유지됩니다. **크기 ▸ 사용자 지정…**에서 영상 영역의 너비 × 높이를 포인트 단위로 입력하면 캡처 중 다른 값이 원본 비율에 맞춰 바뀝니다. Enter로 적용하고 Esc로 취소합니다.
5. PiP 창에 마우스를 올리면 상태, 창 선택, 영역 선택, 닫기 컨트롤이 나타납니다.

### 여러 PiP

메뉴 막대에서 **새 PiP**(⌘N)를 선택하면 PiP 창이 하나 더 열립니다. 새 창은 가장 최근 PiP 창에서 조금 비켜난 위치에 창 목록과 함께 열립니다. PiP마다 창, 영역, 프레임 레이트, 불투명도, 회전, 크기를 따로 가집니다.

**preview.6과 현재 소스 빌드**에서 PiP를 숨기면 캡처 픽셀의 표시가 즉시 차단·초기화되고 스트림은 비동기로 중지됩니다. 숨기는 즉시 스트림이 이미 해제된 것은 아닙니다. 실행 중인 세션의 원본과 설정은 남습니다. **PiP 보이기**는 일시 중지된 창만 표시하며 자동으로 캡처하지 않습니다. **캡처 재개**를 명시적으로 선택하세요. 목록 권한으로 실행 중인 동일 앱과 창을 검증할 수 있으면 창을 새로 조회하고, 그렇지 않으면 시스템 선택기에서 다시 선택합니다. 원본 크기가 바뀌었다면 전체 창 미리보기부터 시작하며 **이전 영역 적용…**을 누르면 **이전 영역을 적용할까요?** 확인을 거쳐야 이전 영역이 적용됩니다. 마지막 PiP가 아닌 창을 닫으면 제거됩니다. **모두 닫기**는 숨겨진 세션도 중지하고 빈 PiP 하나를 숨겨 둡니다.

### 원본 앱으로 이동과 설정 저장

**원본 앱으로 이동**은 검증된 실행 중인 원본 앱을 활성화하며 특정 창에 초점을 맞추지 않습니다. 앱을 확인할 수 없으면 다른 앱을 임의로 실행하지 않습니다. **현재 설정 기억**은 앱 이름/번들 힌트, 정규화된 영역, 원본 크기, 프레임 레이트, 불투명도, 회전을 로컬에 한 건만 선택적으로 저장합니다. 원본 픽셀, 창 제목·ID, PID, 캡처 권한은 저장하지 않습니다. **저장된 설정 삭제**로 지울 수 있습니다. 다음 실행에서 복원하려면 **저장된 설정 복원…**을 명시적으로 선택하고 시스템 선택기나 선택적 목록에서 새 창을 고른 뒤 전체 창 미리보기를 확인하고 **저장된 영역/설정 적용**을 선택·확인하세요. 앱이나 원본 크기가 다르면 적용 전에 이를 알려 주며 영역에 다른 내용이 표시될 수 있습니다. 새 선택을 취소하면 캡처가 시작되지 않고 적용 확인을 취소하면 저장된 설정을 적용하지 않은 채 미리보기가 유지됩니다. 자동 원본 매칭이나 자동 캡처는 하지 않습니다.

### 영역 선택

창을 캡처하는 동안 **영역 선택…**(또는 PiP 창의 영역 선택 버튼)을 누릅니다. 화면 위를 드래그해 영역을 그리고, 영역을 옮기거나 핸들로 크기를 조절합니다. Shift를 누르고 있으면 비율이 유지됩니다. Return(또는 영역 더블클릭)으로 적용하고, Esc로 취소하며, **전체 창**을 누르면 창 전체로 돌아갑니다. 메뉴의 **영역 초기화**로도 창 전체를 다시 표시할 수 있습니다.

영역 선택 오버레이는 영상 영역이 허용하는 한 각 변이 최소 16포인트여야 합니다. 캡처는 원본의 가로 또는 세로 1%보다 작은 정규화 영역을 거부합니다. 영역 좌표는 표시된 원본 창에 대해 정규화하여 저장하고, 캡처할 때 실제 현재 원본 창 크기에 맞춰 변환합니다. 원본 크기가 바뀌면 이전 영역에 다른 내용이 보이거나 영역이 맞지 않을 수 있으므로 전체 창을 미리 본 뒤 이전/저장 영역을 명시적으로 적용하거나 새로 선택하세요.

### 클릭 통과

클릭 통과를 켜면 PiP 창이 마우스를 무시해 클릭이 아래 창으로 전달되고, 각 PiP 창 오른쪽 위에 클릭 통과 배지가 표시됩니다. 어느 앱에서든 ⌃⌥P를 누르거나 메뉴 막대의 **클릭 통과**로 전환합니다. 모든 PiP에 함께 적용됩니다. 단축키는 설정에서 끌 수 있습니다.

### 메뉴 막대

메뉴 이름은 시스템 언어를 따릅니다.

PiP가 하나일 때는 그 PiP의 항목이 메뉴에 바로 나열됩니다. 둘 이상이면 PiP마다 번호와 원본 창 이름이 붙은 하위 메뉴(예: `1. Safari`, `2. 비어 있음`)가 생기고, 그 안에 해당 PiP의 항목이 들어갑니다.

PiP별 항목:

| 메뉴 | 동작 |
| --- | --- |
| 창 선택 ▸ | 선택적 창 목록(⌥를 누르면 영역 선택까지), 기본 동작은 **시스템 선택기로 창 선택…** |
| PiP 숨기기 / PiP 보이기 | 숨기면 픽셀을 즉시 차단·지우고 스트림은 비동기로 중지, 보이기는 캡처를 다시 시작하지 않고 일시 중지된 창만 표시 |
| 영역 선택… | 표시할 창 영역 선택 |
| 영역 초기화 | 창 전체를 다시 표시 |
| 프레임 레이트 ▸ | 1 / 5 / 15 / 30 / 60fps, 즉시 적용 |
| 불투명도 ▸ | 100% / 75% / 50% / 25% |
| 화면 회전 | 누를 때마다 PiP 화면을 시계 방향으로 90° 회전(항목에 현재 각도 표시), PiP 창의 화면 영역 가로·세로가 바뀜. 다음 실행까지 회전을 유지하려면 설정을 명시적으로 기억해야 함 |
| 크기 ▸ | PiP 창 크기 변경: 작게 / 보통 / 크게 / 사용자 지정… |
| 캡처 재개 / 원본 앱으로 이동 | 중지된 캡처를 명시적으로 재개 / 검증된 실행 중인 원본 앱을 활성화(특정 창에 초점을 맞추는 기능이 아님) |
| 중지 | 캡처 중지. 자동 재개하지 않음 |
| PiP 닫기 | 이 PiP 닫기(PiP가 둘 이상일 때 표시) |

공통 항목:

| 메뉴 | 동작 |
| --- | --- |
| 새 PiP ⌘N | PiP 창을 하나 더 열기 |
| 클릭 통과 ⌃⌥P | 모든 PiP의 클릭 통과 전환 |
| 모두 닫기 | 모든 PiP의 캡처를 중지하고 닫기, 빈 PiP 하나는 숨긴 상태로 유지 |
| 설정… ⌘, | 설정 창 열기 |
| 종료 | 앱 종료 |

**현재 설정 기억**과 **저장된 설정 삭제**로 선택적 로컬 설정을 관리합니다. **저장된 설정 복원…**은 새 원본 선택과 전체 창 미리보기를 시작하고 **저장된 영역/설정 적용**은 확인을 요청합니다. 동일 프로세스의 원본 크기가 바뀐 뒤 재개한 경우에는 **이전 영역 적용…**으로 별도로 확인해야 합니다.

### 설정

- **로그인 시 실행**
- **원본 창이 닫히면 PiP 닫기**: 끄면 PiP 창이 열린 채로 원본 창이 닫혔다고 표시
- 새 PiP에 적용할 **기본 프레임 레이트**와 **기본 불투명도**(20–100%)
- **클릭 통과 전환** 단축키(⌃⌥P) 켜기/끄기
- 앱 버전

## 소스에서 빌드

Swift 6 이상 툴체인(Xcode 16 이상 또는 Command Line Tools)이 필요합니다.

```sh
git clone https://github.com/hanbong5938/pip.git
cd pip
bash scripts/build-app.sh release   # 또는 debug
open build/Pip.app
```

스크립트는 SwiftPM으로 빌드한 실행 파일, Metal 셰이더 리소스 번들, 앱 아이콘을 `build/Pip.app`으로 묶고 ad-hoc 서명합니다. `scripts/make-icon.swift`를 고친 뒤 아이콘을 다시 만들려면 `swift scripts/make-icon.swift Resources/AppIcon.icns`를 실행하세요.

저장된 설정의 실제 `SavedSetupStore` 동작을 분리된 `UserDefaults`로 검사하는 이식 가능한 회귀 검사를 저장소 루트에서 실행하려면:

```sh
bash scripts/check-saved-setup.sh
```

Swift 6 이상이 필요하며 Command Line Tools로 충분합니다. XCTest나 Swift Testing 프레임워크에는 의존하지 않습니다. 캡처 동의가 있는 Mac에서의 실제 UI 인수 확인을 대신하지는 않습니다.

잠금 해제된 Mac의 AppKit 그래픽 세션에서 네이티브 캡처 꺼짐 상태의 수명주기 스모크 검사를 실행하려면 먼저 디버그 앱을 빌드한 뒤 실행하세요.

```sh
bash scripts/build-app.sh debug
bash scripts/check-native-state.sh
```

이 검사는 실제 AppKit 창, 세션, 관리자의 숨기기/보이기/모두 닫기/종료 전환을 캡처가 꺼진 상태에서 확인합니다. 가짜 원본이나 스트림을 만들거나 선택기·권한 요청을 열지 않으며 실제 캡처 성공을 증명하지 않습니다. 화면이 잠기면 원본에 의존하는 검사는 수행할 수 없습니다. 아래의 선택기·캡처·저장된 설정 복원 수동 인수 확인에는 잠금 해제된 GUI와 실제 사용자 동의가 필요합니다.

## 알려진 제한

- PiP 창이 다른 데스크톱에 보이더라도 원본 프레임이 새로 들어오지 않을 수 있습니다. 원본 앱이 렌더링을 멈추면 PiP가 강제로 다시 그리게 할 수 없습니다.
- Chrome 동영상이 다른 데스크톱에서 같은 프레임을 반복한 사례가 있습니다. macOS 기본 시계처럼 백그라운드에서도 그리는 앱은 계속 갱신될 수 있습니다. 모든 원본의 동작을 보장하지 않습니다.
- 창별 화면 기록 권한만 있는 상태는 검증되지 않았습니다. 선택적 창 목록은 열기·새로 고침·선택 시 ScreenCaptureKit으로 창을 다시 조회합니다. 목록을 사용할 수 없으면 시스템 선택기를 사용하세요.
- 앱이 ad-hoc 서명이라 로그인 시 실행을 켜면 **시스템 설정 › 로그인 항목**에서 허용해야 할 수 있습니다. 허용이 필요하면 설정 창에 해당 화면을 여는 버튼이 표시됩니다.
- 영역은 원본 창에 대한 정규화 좌표로 저장되며, 캡처할 때 실제 원본 창 크기에 맞춰 변환합니다. 원본 창을 조절하면 의도한 내용이 달라지거나 이전 영역이 맞지 않을 수 있습니다. 먼저 전체 창을 미리 보고 **이전 영역 적용…** 또는 **저장된 영역/설정 적용**을 확인하거나 영역을 다시 선택하세요.
- PiP 창은 앱을 활성화하지 않기 때문에, 다른 앱이 활성 상태일 때는 가장자리에 마우스를 올려도 크기 조절 커서로 바뀌지 않습니다. 가장자리를 드래그하면 크기 조절은 됩니다. 백그라운드 앱이 커서를 바꾸는 공개 API는 없습니다.

## 수동 인수 확인 및 7일 관찰

**preview.6 및 현재 소스 빌드 UI 인수 확인**에는 macOS 15.2 이상 Apple Silicon Mac에서 공개 바이너리라면 위 파일 두 개를 받아 `OK`를 확인하고 릴리스 URL을 기록하세요. 소스 빌드라면 위 지침으로 앱을 빌드하고 소스 리비전을 기록하세요. OS 버전, Gatekeeper 실행 결과, 캡처 권한 상태도 기록하세요. 실제 로그/빌드 창과 대시보드로 목록 권한 없이 **시스템 선택기로 창 선택…**부터 시작하세요. 원본이 실제로 그리는 동안의 프레임 갱신, 중지, 숨김(픽셀은 바로 지워지고 스트림은 비동기로 종료), 보이기(자동 재개 없음), 명시적 재개, **원본 앱으로 이동**(특정 창이 아닌 앱 활성화)을 확인하세요. 원한다면 더 넓은 화면 기록 권한을 허용하고 목록에서 반복해 목록 로딩 실패와 선택 전 창 닫힘도 확인하세요. 선택기 취소·다른 PiP의 선택기 사용 중·일시 중지 중 원본 크기 변경(전체 창 미리보기와 **이전 영역 적용…** 확인)·클릭 통과·여러 PiP·모두 닫기·종료 후 재실행(자동 캡처 없음)을 점검하세요. **현재 설정 기억**을 선택하고 다시 실행해 **저장된 설정 복원…**에서 새 원본을 선택한 뒤 전체 창 미리보기, 앱/크기 불일치 알림, **저장된 영역/설정 적용** 확인을 점검하고 **저장된 설정 삭제**를 선택하세요. 실제 결과와 실패를 기록하되 창이 보인다는 이유만으로 프레임 갱신을 단정하지 마세요.

7일 수동 관찰에는 실제 동의한 사용자가 매일 평소의 로그/빌드 또는 대시보드 작업을 수행하도록 요청하세요. 날짜, macOS 버전, 원본 앱, 선택 경로와 권한 상태, 다른 데스크톱에서 원본의 렌더링 지속 여부, 캡처·숨김·재개 결과, 불일치 안내, 사용자가 말한 불편을 비공개 수동 기록으로 남깁니다. 스크린샷·원본 내용·자동 분석 데이터는 수집하지 않습니다. 실제로 확인한 관찰과 참여 인원·일수만 요약하고 외부 참가자가 없으면 이를 명시하세요. 참여하지 않은 사용자의 평가나 측정하지 않은 신뢰도를 만들어 내지 마세요.
