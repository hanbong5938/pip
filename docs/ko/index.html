PiP에 필요한 모든 것

영상 플레이어뿐 아니라 어떤 창이든. ScreenCaptureKit으로 캡처하고 Metal로 렌더링합니다.

01

모든 창

앱 안의 창 목록이나 macOS 시스템 선택기에서 창을 고르면, 모든 데스크탑(Space)과 전체 화면 앱 위에 항상 떠 있는 패널로 실시간 표시합니다.

02

여러 개의 PiP

⌘N으로 필요한 만큼 패널을 엽니다. 각 PiP는 자기 창과 설정, 크기, 위치를 따로 가집니다.

03

영역 선택

패널 위에서 바로 드래그해 필요한 부분만 보여줍니다. 채팅 창, 앨범 아트, 차트 하나만.

04

프레임 레이트 · 불투명도

PiP마다 1 / 5 / 15 / 30 / 60 fps와 불투명도를 따로 설정. 캡처 해상도는 패널 크기를 따릅니다.

05

클릭 통과

어느 앱에서든 ⌃⌥P로 켜고 끕니다. 켜면 클릭이 패널을 지나 아래 창으로 전달됩니다.

06

회전 · 크기

영상을 90°씩 회전하고, 작게 / 보통 / 크게 또는 정확한 사용자 지정 크기로. 비율은 그대로 유지됩니다.

07

메뉴 막대 전용

Dock 아이콘 없음. 패널 위 호버 컨트롤, 로그인 시 실행과 새 PiP 기본값을 고르는 설정 창.

08

한국어 · 영어

UI가 시스템 언어를 따릅니다.

09

개인정보 보호

프레임은 기기 안에서만 처리되며 저장하거나 네트워크로 보내지 않습니다.

설치

Homebrew로 설치하면 업데이트도 간편합니다.

🍺 Homebrew 추천

개인 탭 hanbong5938/homebrew-tap으로 배포됩니다.

설치

brew install --cask hanbong5938/tap/pip

업데이트

brew update && brew upgrade --cask pip

삭제

brew uninstall --cask pip

📦 직접 다운로드

  1. Releases에서 PiP-v<version>-macos-arm64.zip과 SHA256SUMS.txt를 받습니다.
  2. 체크섬을 확인합니다:
    shasum -a 256 -c SHA256SUMS.txt
  3. 압축을 풀고 Pip.app을 /Applications로 옮겨 실행합니다.
  4. 처음 사용할 때 화면 기록 권한을 허용합니다.
Gatekeeper: 이 앱은 ad-hoc 서명만 되어 있고 Developer ID 서명과 Apple 공증(notarization)이 없습니다. macOS가 실행을 막으면, 출처와 체크섬을 확인한 경우에만 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기로 허용하세요.

시스템 요구 사항

  • Apple Silicon(arm64) Mac
  • macOS 15.2 이상
  • 화면 기록 권한

알려진 제한

  • 원본 앱이 다른 데스크탑(Space)에서 그리기를 멈추면 PiP 패널도 멈춥니다.
  • 오디오는 캡처하지 않으며, 패널에서의 클릭·키 입력은 원본 창으로 전달되지 않습니다.
  • 로그인 시 실행은 시스템 설정 › 로그인 항목에서 승인이 필요할 수 있습니다.

개인정보 처리

PiP는 선택한 창을 패널에 실시간으로 보여주기 위해서만 화면 기록 권한을 요청합니다. 프레임은 Mac의 메모리 안에서만 처리되며 녹화·저장·업로드·공유되지 않습니다. 분석·추적 도구와 네트워크 요청이 없고, 설정은 기기의 UserDefaults에만 저장됩니다.
