Keep logs and build progress in view while you work.

PiP mirrors a window into a small, always-on-top read-only panel. Watch a terminal build or log while working in another app.

Free & open source · Published preview.6 (pinned download)

A small window on work in progress

Mirror a selected window with ScreenCaptureKit and Metal. The panel observes it; it does not control the source.

01

Choose a window

Observe a selected window, subject to the source continuing to render. In the current source build, start with Choose with System Picker…; its optional in-app window list needs broader Screen Recording permission.

02

Multiple PiPs

Open as many panels as you need with ⌘N. Each one mirrors its own window with its own settings, size, and position.

03

Region capture

Select part of the source window, such as a build status area or chart, for read-only viewing.

04

FPS & opacity

1 / 5 / 15 / 30 / 60 fps and adjustable opacity per PiP. Capture resolution follows the panel size.

05

Click-through

Toggle with ⌃⌥P from any app so clicks pass through the panels to the windows underneath.

06

Rotate & resize

Rotate the panel image in 90° steps, use Small / Medium / Large presets or an exact custom size; aspect ratio stays locked.

07

Menu bar only

No Dock icon. Hover controls on each panel, a Settings window with launch at login, and defaults for new PiPs.

08

English & Korean

The UI follows your system language.

09

Private by design

Captured frames are processed on-device, not saved or sent over the network.

Included in preview.6: Hide PiP clears the panel and stops capture (stream teardown is asynchronous); Show PiP does not restart it. Choose Resume Capture explicitly, reselecting with the system picker if the same running source cannot be verified. Open Source App activates the verified running app, not a specific window. Opt in with Remember Current Setup; later use Restore Saved Setup… to select a fresh window, inspect a full-window preview, then Apply Saved Region/Settings with confirmation. A different app or window size is disclosed before applying; crop content may differ. No automatic capture or saved window access. Live capture and restore require manual validation on an unlocked Mac.

📦 Manual download · v1.0.0-preview.6

  1. Download the arm64 ZIP and matching SHA256SUMS.txt into the same folder (for example, Downloads).
  2. In Terminal, enter that folder and check the ZIP against the listed hash:
    cd ~/Downloads && shasum -a 256 -c SHA256SUMS.txt
    Look for PiP-v1.0.0-preview.6-macos-arm64.zip: OK. If either file is missing, the command fails, or the ZIP reports FAILED, stop and re-download both from the same release. A checksum match checks against the downloaded manifest, not publisher identity or safety.
  3. Unzip, move Pip.app to /Applications, and launch it.
Gatekeeper: this experimental app is ad-hoc signed only — it has no Developer ID signature and is not notarized by Apple. If macOS blocks it, only after independently trusting the release source and checking the checksum, use System Settings → Privacy & Security → Open Anyway if you accept that risk. Do not disable Gatekeeper or remove quarantine.
First use of the pinned preview.6 ZIP or a current source build: Open PiP from the menu bar and choose Choose with System Picker…; select a window when macOS asks. This route does not require the broader Screen Recording permission needed for the optional Choose Window ▸ in-app list. Only grant that broader permission if you want the list. Move or resize the panel; use Select Region… to observe part of the window. Usage guide.

System requirements

  • Apple Silicon (arm64) Mac
  • macOS 15.2 or later
  • macOS capture consent for your selection route; broader Screen Recording permission only for the optional source-build window list

Known limitations

  • If the source app stops rendering while it is on another desktop (Space), the PiP panel freezes too.
  • No audio capture; clicks and keystrokes are not forwarded to the source window.
  • Launch at login may need approval in System Settings › Login Items.

Privacy

Frames are processed in memory on your Mac, not recorded, saved, uploaded, or shared. There is no analytics or tracking. Settings are local; the current source build saves a setup recipe only when you choose Remember Current Setup, never source pixels or capture authorization. macOS may request capture consent for your chosen route.
